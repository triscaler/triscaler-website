01

A local AI model adds context

A small AI model runs on the Mac and adds context to other credential checks. It cannot create a finding by itself. Scanning does not send content to a cloud AI service.

02

Check supported AI chat records

Triscaler checks selected Claude Code, Cline, Gemini CLI and Copilot records stored on the Mac. A chat match only counts when the same credential is verified in an unchanged source file. Chat text is not uploaded, and desktop prompts are not checked before sending.

03

See limited AI-app connection details

On Mac, Triscaler can associate some outgoing connections with recognized AI apps. This is best-effort metadata. It does not read prompts, inspect encrypted traffic or block connections.

AI limits: desktop prompts are not intercepted. Chat records are checked only when a credential matches an unchanged source file. Browser checks cover selected flows. Connection monitoring is best-effort metadata and may miss activity.

Designed for accountable response

Know what was found, why it matters and what happened next.

  1. Discover locally: The macOS agent checks supported sources on the endpoint and paces background work to reduce disruption.
  2. Validate the evidence: Structural checks, checksums, identity context and corroborating signals help distinguish credentials from ordinary text.
  3. Connect the sightings: Fingerprints and account attribution link the same credential across files and machines, with an origin and timeline.
  4. Deliver controlled updates: Enrolled agents verify signed, versioned rule and policy bundles delivered by the server, then hot-reload them.
  5. Investigate and act: Analysts review evidence and audit history. An endpoint rotation report is recorded as an attestation, not automatic proof of revocation.

Inspect locally. Share deliberately.

Triscaler does not upload whole source files or full browser prompts. A policy-approved finding may still include the matched value so an authorized team can investigate and rotate it.

  • Local findings are encrypted in the agent database.
  • Matched values are encrypted at rest on the server; revealing one is audited.
  • Agent requests use per-device Ed25519 signatures. Remote deployments should use HTTPS/TLS.
  • Browser prompt text is not retained or uploaded; outbound AI monitoring stores connection metadata only.
Current scope: macOS endpoint agent and a central web console. Browser coverage depends on extension permissions and supported flows; outbound AI-tool monitoring is best-effort metadata, not content inspection. Triscaler does not currently block network traffic or quarantine files, and broad health-record/PII discovery is not included. The Windows agent is planned and is not available yet.
